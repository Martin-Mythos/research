执行摘要

HTML-Anything

自由语义 DOM，适合 dashboard、长文与源码级二次编辑；LLM 合规是软约束。

Bento

固定单文件 runtime + JSON slide model，演示状态、GUI 编辑与运输更强。

最佳上下文工程

分离 canonical facts、style 和 output contract；用外部 validator，不依赖 silent self-check。

模型边界：没有 Opus 5 / GPT-5.6-Sol API key；没有执行真实模型 A/B，不能报告模型胜负。
